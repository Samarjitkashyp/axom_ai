Integration Quickstart

Connect to Axom AI in Under 2 Minutes

Axom AI endpoints are 100% compatible with the OpenAI API format.

curl https://aiaxom.co.in/v1/chat/completions   -H "Content-Type: application/json"   -H "Authorization: Bearer YOUR_AXOM_API_KEY"   -d '{
    "model": "axom-gpt-4o",
    "messages": [
      {"role": "system", "content": "You are Axom AI assistant."},
      {"role": "user", "content": "Hello! How do you say welcome in Assamese?"}
    ]
  }'
from openai import OpenAI

# Point the standard OpenAI SDK to Axom AI Base URL
client = OpenAI(
    api_key="YOUR_AXOM_API_KEY",
    base_url="https://aiaxom.co.in/v1"
)

response = client.chat.completions.create(
    model="axom-gpt-4o",
    messages=[
        {"role": "system", "content": "You are an expert bilingual AI assistant."},
        {"role": "user", "content": "Explain quantum computing in simple words."}
    ]
)

print(response.choices[0].message.content)
import OpenAI from "openai";

// Point the official OpenAI npm library to Axom AI
const client = new OpenAI({
  apiKey: "YOUR_AXOM_API_KEY",
  baseURL: "https://aiaxom.co.in/v1"
});

async function main() {
  const response = await client.chat.completions.create({
    model: "axom-gpt-4o",
    messages: [
      { role: "user", content: "Build a Next.js component in TypeScript." }
    ],
  });

  console.log(response.choices[0].message.content);
}

main();

SDK Integration Guide

Connect with OpenAI Python & Node.js SDKs

Zero code overhaul. Replace the base URL and pass your Axom secret key.

Base URL: https://aiaxom.co.in/v1
Python (openai >= 1.0.0) 
from openai import OpenAI

client = OpenAI(
    base_url="https://aiaxom.co.in/v1",
    api_key="YOUR_AXOM_SECRET_KEY"
)
response = client.chat.completions.create(
    model="axom-indic",
    messages=[{"role": "user", "content": "Hello Axom AI"}]
)
print(response.choices[0].message.content)
