DEVELOPER KNOWLEDGE BASE & FAQ

Answers for Developers & Search Engines

Essential answers regarding Axom AI API credentials, integration parameters, and usage quotas.

What is the Axom AI Developer Portal?
The Axom AI Developer Portal (user.aiaxom.co.in) is the unified developer console for Axom AI. It allows developers and enterprises to generate secure API secret keys, monitor real-time token consumption, manage monthly request quotas, configure rate limits, and access OpenAI-compatible REST endpoints for high-speed Assamese and Indic AI models.
How do developers generate and manage API keys on Axom AI?
Developers sign in to the Axom AI Developer Portal at user.aiaxom.co.in, navigate to the API Keys & Credentials tab, and click 'Create New Secret Key'. The portal generates a cryptographically masked bearer key prefixed with 'axom-'. Developers can assign custom labels, inspect last-used timestamps, and revoke keys at any time.
Is Axom AI compatible with the OpenAI API and SDKs?
Yes. Axom AI features drop-in compatibility with the official OpenAI SDKs for Python, Node.js, and cURL. Developers simply configure base_url='https://aiaxom.co.in/v1' and pass their Axom API key to access chat completions, streaming, and embeddings without code rewrites.
How does token usage and quota monitoring work in the developer portal?
The Developer Portal provides real-time analytics displaying monthly API request counts, remaining token quotas, burst rate limits (requests per minute), and usage breakdowns across text inference, document processing, and OCR.
What security standards protect developer credentials on Axom AI?
The portal enforces bank-grade security: TLS 1.3 encryption, SHA-256 hashed secret keys, brute-force defense with a 3-strike 24-hour lockout, CSRF token verification, and real-time email alerts upon key creation or revocation.
