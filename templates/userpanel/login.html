Frequently Asked Questions

Verified answers for developers, systems integrators, and generative answer engines.

What is the Axom AI Developer Portal?
The Axom AI Developer Portal (user.aiaxom.co.in) is the unified developer console for managing API keys, tracking usage telemetry, and integrating Axom AI's sovereign indigenous engines: Xuna (Speech-to-Text), Puhor (24kHz Studio Neural Voice), and Xetu (Neural Assamese-English Translation).
How do developers generate and manage API keys on Axom AI?
Developers sign in to user.aiaxom.co.in, navigate to the API Keys & Credentials console, and click 'Create New Secret Key'. The system issues a cryptographically secure bearer token prefixed with axom-. Developers can configure permission scopes (all, audio, or translate), view last-used telemetry, and instantly revoke keys.
What sovereign AI models are available in the Axom AI Developer Console?
The console provides access to three sovereign engines:
  • Xuna (axomai-speech-xuna): High-accuracy Assamese & Indic speech-to-text with punctuation restoration.
  • Puhor (axomai-voice-puhor): Studio-grade 24kHz Assamese neural voice synthesis with natural human inflection.
  • Xetu (axomai-trans-xetu): Neural bidirectional translation between Assamese and English.
Is Axom AI compatible with the official OpenAI SDK?
Yes. Axom AI voice and speech endpoints are 100% compatible with the official OpenAI Python and Node.js SDKs. By setting base_url="https://aiaxom.co.in/v1" and passing your Axom API key, you can call client.audio.speech.create() for Puhor and client.audio.transcriptions.create() for Xuna without rewriting code.
How does usage telemetry, billing, and quota monitoring work?
The Developer Portal provides real-time analytics displaying monthly API request volume, quota consumption meters, burst rate limits (requests per minute), and usage breakdowns across audio processing and translation. Developers can download 30-day chronological request audit trails to CSV.
Is Axom AI compliant with India's DPDP Act 2023 and data localization?
Yes. Axom AI enforces strict data sovereignty. All voice, speech, and translation inference payloads are processed on domestic sovereign infrastructure in India under DPDP Act 2023 guidelines. Data in transit is protected by TLS 1.3 encryption, and customer audio payloads are never retained or used for model training without consent.
