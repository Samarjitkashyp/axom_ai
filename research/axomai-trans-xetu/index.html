1. The Historic Milestone for Assam

Until today, translation between English and Assamese on commercial cloud systems was plagued by severe inaccuracies and broken syntax. Because Assamese is an agglutinative language where grammatical relationships are expressed via complex postpositions (বিভক্তি: -ৰ, -লৈ, -ত, -দ্বাৰা, -ক), generic models frequently drop case endings, invert active and passive clauses, and produce literal, nonsensical translations of legal and administrative records.

Moreover, transmitting sensitive government gazettes, court filings, and educational materials across foreign commercial APIs creates significant data sovereignty vulnerabilities. We built Axom AI Bridge — Xetu (সেতু) directly in Guwahati to provide Assam's native answer: a 200 Million parameter sequence-to-sequence neural translation bridge specifically tuned on parallel corpora spanning governance, legal statutes, agricultural extension, and academic curricula.

3. Deep Neural Architecture & Execution Pipeline

Axom AI Xetu is instantiated as a custom IndicTransForConditionalGeneration architecture with 36 Transformer blocks (18 encoder layers and 18 decoder layers). Unlike shallow models, this deep representation enables rich contextual modeling of the morphological nuances separating Indo-Aryan and Tibeto-Burman linguistic features prevalent across Assam.

Architectural Specifications & Tensor Topology

  • Layer Topology: 18 Encoder Layers + 18 Decoder Layers (Total 36 Transformer Layers) with Pre-Layer Normalization (decoder_normalize_before: true).
  • Dimensional Geometry: Embedding Dimension $d_{model} = 512$, Intermediate Feed-Forward Dimension $d_{ffn} = 2048$, with 8 parallel attention heads per block.
  • Non-Linear Activation: GELU (Gaussian Error Linear Unit) with low-variance weight initialization ($\sigma=0.02$) and scaled embeddings.
  • Vocabulary Topology: Dual SentencePiece dictionaries with 32,322 source subword tokens (dict.SRC.json) and 122,672 target subword tokens (dict.TGT.json), resolving Latin script transliterations and Bengali/Assamese script characters without unknown token decay.
  • Binary Distribution: Formatted in zero-copy model.safetensors (1,047.54 MB), enabling instant memory-mapped loading ($mmap$) in under 400 milliseconds on commodity CPU hardware.
  • Domain Alignment: Adapted against the custom-assamese-parallel dataset, encompassing 1,250 verified bilingual evaluation sets for state governance, civil engineering, land laws, and cultural literature.

Xetu translates between English and Assamese through four synchronized neural stages:

  1. Subword Segmentation & Language Tagging: Source text is prepended with target and source language tokens (eng_Latn, asm_Beng) and tokenized across the unified vocabulary, preserving compound Assamese ligatures (যুটীয়া আখৰ: ক্ষ, জ্ঞ, ত্ৰ, হ্ন).
  2. 18-Layer Deep Contextualization: The multi-layer transformer encoder builds continuous semantic representations of the entire source sentence, preserving thematic dependencies across long clause boundaries.
  3. Autoregressive Decoder with Cross-Attention: The 18-layer decoder generates the target translation token-by-token while cross-attending to encoder representations, enforcing strict grammatical agreement in noun-verb conjugations and postpositions.
  4. 4-Beam Search Ranking: Hypotheses are dynamically ranked using beam search with length penalties ($lpha=1.0$), selecting the most fluent, grammatically natural Assamese formulation.

7. Quick Start: Hugging Face Python Integration

Axom AI Xetu is loaded seamlessly via the Hugging Face transformers library using trust_remote_code=True (which executes the optimized configuration_indictrans.py, modeling_indictrans.py, and tokenization_indictrans.py scripts directly from the repository):

xetu_inference.py — Official Integration 
import torch
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

# 1. Model credentials and Hugging Face repository
REPO_ID = "axom-ai/axomai-trans-xetu"
HF_TOKEN = "your_hf_access_token"  # Provide your authorized HF access token

# 2. Load tokenizer and 200M Seq2Seq model from Hugging Face Hub
tokenizer = AutoTokenizer.from_pretrained(REPO_ID, token=HF_TOKEN, trust_remote_code=True)
model = AutoModelForSeq2SeqLM.from_pretrained(REPO_ID, token=HF_TOKEN, trust_remote_code=True)

# 3. Bidirectional Example A: English to Assamese Translation
english_text = "Welcome to Axom AI, the native artificial intelligence ecosystem of Assam."
inputs_en = tokenizer([english_text], src_lang="eng_Latn", tgt_lang="asm_Beng", return_tensors="pt")

with torch.no_grad():
    outputs_en = model.generate(**inputs_en, max_length=256, num_beams=4)

translation_as = tokenizer.batch_decode(outputs_en, src_lang="eng_Latn", tgt_lang="asm_Beng")[0]
print(f"Assamese Output: {translation_as}")
# Output: অসমৰ থলুৱা কৃত্ৰিম বুদ্ধিমত্তা পৰিস্থিতিতন্ত্ৰ, অসম এআইলৈ আপোনাক স্বাগতম।

# 4. Bidirectional Example B: Assamese to English Translation
assamese_text = "অসমৰ থলুৱা কৃত্ৰিম বুদ্ধিমত্তা পৰিস্থিতিতন্ত্ৰ, অসম এআইলৈ আপোনাক স্বাগতম।"
inputs_as = tokenizer([assamese_text], src_lang="asm_Beng", tgt_lang="eng_Latn", return_tensors="pt")

with torch.no_grad():
    outputs_as = model.generate(**inputs_as, max_length=256, num_beams=4)

translation_en = tokenizer.batch_decode(outputs_as, src_lang="asm_Beng", tgt_lang="eng_Latn")[0]
print(f"English Output: {translation_en}")
# Output: Welcome to Axom AI, the indigenous artificial intelligence ecosystem of Assam.
