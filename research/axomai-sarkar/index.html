Axom AI Sarkar (অসম চৰকাৰ AI সহায়ক) is Assam's sovereign 492 Million parameter Small Language Model (SLM) specialized in public administration, land revenue, citizen rights, and government schemes. Unlike generic commercial LLMs that frequently hallucinate statutory fees, confuse Assam land regulations (ALRR 1886) with other states, or fail to understand the Assam Right to Public Services (ARTPS) penalty framework, Axom AI Sarkar provides 100% factual, step-by-step guidance in Assamese, English, and Hindi. 1. The Historic Milestone for Assam Governance

Until today, citizens and Common Service Centre (CSC) operators seeking answers regarding Assam Government procedures had to rely on commercial cloud LLMs (such as ChatGPT or Gemini). These models routinely hallucinate critical governance facts: inventing non-existent portal fees, quoting outdated land tenancy rules, missing the statutory ₹250/day penalty under the ARTPS Act 2012, and failing to comprehend the post-2023 Delimitation boundaries of Assam's 130 Legislative Assembly Constituencies.

To eliminate legal inaccuracy and guarantee public access without costly GPU cloud subscriptions, we engineered Axom AI Sarkar directly in Guwahati. It is a 492 Million parameter Small Language Model natively trained on authoritative government acts, gazette circulars, departmental workflows, and dispute escalation matrices.

3. Deep Neural Architecture & Execution Pipeline

Axom AI Sarkar is built on a high-efficiency Qwen 2.5 Base architecture (~492 Million parameters) quantized to GGUF Q4_K_M (4-bit Medium K-Quant). The model employs a standard ChatML prompt topology with an expanded 4,096 token context window, enabling it to ingest full statutory notifications, multi-tier appeal memos, and complete citizen complaint dossiers in a single inference pass.

Architectural Specifications & Operational Metrics

  • Base Architecture: Qwen 2.5 Base (492 Million parameters) with Rotary Position Embedding (RoPE) and RMSNorm pre-layer normalization.
  • Quantization Format: GGUF Q4_K_M (4-bit medium k-quantization with float16 scale preservation), resulting in a compact 468.64 MB binary distribution.
  • Context Window Geometry: 4,096 tokens ($n_{ctx} = 4096$), comfortably supporting multi-document legal citations and dispute escalation matrices.
  • Memory Footprint: ~350 MB to 500 MB active RAM consumption, allowing persistent daemon operation on 2 GB RAM budget servers or edge kiosks.
  • Prompt Topology: ChatML prompt format (<|im_start|>system...<|im_end|>) with native trilingual prompt steering in Assamese, English, and Hindi.
  • Retrieval Augmentation: Coupled with an in-memory BM25 retrieval engine indexing 482 official government knowledge documents across 48 modular domains.

7. Quick Start: Python & Ollama Integration

Developers and researchers can run Axom AI Sarkar locally in two simple ways:

Method 1: Run with Ollama (Easiest)

# One-line execution with Ollama
ollama run hf.co/axom-ai/AxomAI-Sarkar:AxomAI-Sarkar-0.5B-Q4_K_M.gguf

Method 2: Run with Python (`llama-cpp-python` — 100% CPU)

from llama_cpp import Llama
from huggingface_hub import hf_hub_download

# 1. Download quantized GGUF from repository
model_path = hf_hub_download(
    repo_id="axom-ai/AxomAI-Sarkar",
    filename="AxomAI-Sarkar-0.5B-Q4_K_M.gguf"
)

# 2. Initialize CPU engine (4 threads, 4096 context window)
llm = Llama(model_path=model_path, n_ctx=4096, n_threads=4)

# 3. Query using ChatML formatting
prompt = """<|im_start|>user
Mission Basundhara 3.0 mein AP to PP patta conversion ke rules kya hain?<|im_end|>
<|im_start|>assistant
"""

output = llm(prompt, max_tokens=300, temperature=0.2)
print(output["choices"][0]["text"])
